
# Slay the Spire 2 v0.114.0 パッチノート日本語訳

2026年11月25日 / パブリックベータ

今回はフールを中心とした大規模なバランス調整です。

> 本記事は非公式の日本語翻訳です。
> 一部のカード名・効果には仮訳が含まれます。

## 変更区分

- 🟢 強化
- 🔴 弱体化
- 🟡 リワーク・効果変更
- 🆕 新規追加

※括弧内の数値はアップグレード後の性能です。

---

# フール

## エポックの変更

### 🟡 私は何者か？

- 解放されるカードを「矢筒」から「矢研ぎ」に変更。

---

## 新規カード

### 🆕 楽観主義（Optimism / 仮訳）

**レア / スキル / 1コスト**

- 手札の「悲しみ」をすべて廃棄する。
- この効果で廃棄したカード1枚につき、カードを1枚引く。
- 廃棄。
- アップグレードすると廃棄がなくなる。

---

## カードのリワーク

### 🟡 成長

**変更前**

- 手札の「悲しみ」をすべて廃棄する。
- 廃棄したカード1枚につき、4（6）ストレッチを得る。

**変更後**

- 8（11）ブロックを得る。
- 手札のランダムな「悲しみ」1枚を、このカードのコピーに変化させる。

### 🟡 矢の一突き

**コモン / アタック**

- コスト：1 → 2

**変更前**

- 9（12）ダメージを与える。
- 矢を所持している場合、矢を放つカード1枚を廃棄札から手札に加える。

**変更後**

- 13（15）ダメージを与える。
- 6（8）弓力を得る。

### 🟡 百花繚乱

**レア / スキル**

- コスト：0 → 1

**変更前**

- 矢を放つカードをすべて廃棄し、ザ・ショット（+）を生成する。
- 廃棄。

**変更後**

- 手札のカードを1枚選び、ザ・ショット（+）に変化させる。

### 🟡 ザ・ショット

**生成カード / アタック**

- コスト：1 → 0

**変更前**

- 矢を放ち、百花繚乱で廃棄したカード1枚につき10（13）ダメージを与える。

**変更後**

- 矢を放ち、20（25）ダメージを与える。
- 廃棄。

### 🟡 調律

**アンコモン / パワー**

- コスト：2（1）→ 1

**変更前**

- ターン終了時、キの旋律がある場合、次にプレイするカードのコストが0になる。

**変更後**

- キの旋律を得るたび、手札のランダムなカード1（2）枚をアップグレードする。

### 🟡 ラピッドショット

「ツインショット（Twin Shot / 仮訳）」に名称変更。

- レアリティ：アンコモン → コモン
- コスト：1（変更なし）

**変更前**

- 矢を放ち、3ダメージを3（4）回与える。

**変更後**

- 矢を放ち、7（10）ダメージを2回与える。

### 🟡 リコール

**コモン / スキル**

- コスト：1（0）→ 0

**変更前**

- 敵が刺矢状態の場合、捨て札のカード1枚を山札の一番上に置く。

**変更後**

- 保留。
- 敵が刺矢状態の場合、刺矢を解除する。
- 廃棄。
- アップグレードすると廃棄がなくなる。

### 🟡 トリックショット

**変更前**

- 矢を放ち、12（15）ダメージを与える。
- このカードを手札に戻す。

**変更後**

- 矢を放ち、12（14）ダメージを与える。
- カードを2（3）枚引く。

### 🟢 調和の盾

**変更前**

- 旋律1つにつき、5（7）ブロックを得る。

**変更後**

- 4（6）ブロックを得る。
- 旋律1つにつき、追加で4（6）ブロックを得る。

### 🟡 ワー・キ

**変更前**

- 2（4）ダメージを2回与える。
- 次のターン、1エナジーを得てカードを1枚引く。

**変更後**

- 3（4）ダメージを2回与える。
- 廃棄札からカード1枚を山札の一番上に置く。
